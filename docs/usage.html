Using the app

  1. Open Fleet, select future dates and choose an available car.
  2. Choose self-drive or GearPilot, pickup/dropoff locations, and add-ons. Review the quote before confirming.
  3. Supply customer details and accept the terms. Self-drive also requires a valid licence. Save the returned booking reference.
  4. Use My booking with the reference and email to look up or cancel a future confirmed booking.
  5. Open Staff login to manage cars, bookings, drivers and moderation. Admin credentials are configured locally, never included in these Docs.

Only pay_at_pickup represents an offline payment arrangement. pay_online_demo does not charge money. There is no email/SMS confirmation integration.

Dates use YYYY-MM-DD (UTC); the return date is exclusive. A quote does not reserve a car. A booking can return 409 if the car or driver is no longer available.

Before public production use

        
    
          
  • Integrate a real payment provider and payment verification if accepting online payments; add email/SMS confirmations if required.
    • 
          
  • There are no location-management APIs or image-upload APIs. Locations are seeded in code, and car photos must be deployed as files.
    • 
          
  • Verify prices, deposits, tax, locations, chauffeurs, social links and rental/privacy terms; some content is inferred or demo data.
    • 
          
  • Configure durable hosting, HTTPS, strong admin/JWT secrets, persistent storage, monitoring and scheduled backups. SQLite requires a single app instance with its local persistent disk.
    • 
          
  • A public tunnel exposes the whole app, including guest write APIs and the admin sign-in. Share only synthetic demo data; use an access-controlled tunnel for a development preview.
    •
